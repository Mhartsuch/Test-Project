# Glazing TORMAX TX9500 Door Panels Into the Rail (Shoe)

Work instruction package for wet-setting 1/2" tempered glass into the aluminum
door rails ("shoes") of TORMAX TX9500 all-glass sliding door panels.

---

## Read this first — the Por-Rok answer

You asked whether the Por-Rok on the shelf can be used. **It depends on which
Por-Rok it is and whether the door is exposed to weather.** The two products in
that family have opposite limitations, and each one rules out the other's
application:

| | **POR-ROK** (regular) | **SUPER POR-ROK** |
|---|---|---|
| Base | Gypsum-based | Portland cement-based |
| Bare aluminum contact | **OK** — manufacturer recommends regular Por-Rok for aluminum railings | **NOT OK** — "installing SUPER POR-ROK® to any exposed aluminum will cause uncontrolled expansion"; rail must be coated inside *and* out |
| Water exposure | **NOT OK** — "will exhibit strength loss where left exposed to water"; interior only | **OK** — rated interior and exterior |
| Set time | 20–30 min | 20–30 min |

So:

```
                    Is the panel exposed to weather / washdown /
                          driven rain / floor mopping?
                                     │
                 ┌───────────────────┴───────────────────┐
                NO                                      YES
       (interior vestibule,                   (exterior entrance — the
        mall, lobby slider)                    normal TX9500 case)
                 │                                       │
                 ▼                                       ▼
     ┌───────────────────────┐            ┌──────────────────────────────┐
     │ Use REGULAR POR-ROK   │            │ Regular Por-Rok is NOT       │
     │ straight into the      │            │ suitable — it loses strength │
     │ mill-finish rail.      │            │ when wet.                    │
     │ No isolation coating   │            │                              │
     │ required.              │            │ Use SUPER POR-ROK **and**    │
     │                        │            │ coat the rail interior with  │
     │ ✔ Your on-hand stock   │            │ bituminous coating first.    │
     │   works as-is.         │            │                              │
     └───────────────────────┘            │ ✘ Bare aluminum + Super      │
                                          │   Por-Rok = uncontrolled      │
                                          │   expansion = cracked glass   │
                                          │   / blown rail.               │
                                          └──────────────────────────────┘
```

**Bottom line:** if these are exterior entrance panels — which is the usual
TX9500 install — the regular Por-Rok on hand is the *wrong* product, and Super
Por-Rok is only safe if you first coat the inside of the rail. Confirm which
bucket you have and read that specific bucket's data sheet before mixing
anything. See [02 — Material selection](02-material-selection.md).

**Also confirm with TORMAX before you pour.** Some all-glass rail systems ship
as *dry-glaze* (gasket/wedge) rails, which must never be cemented, and some
manufacturers void warranty on field-cemented rails. See
[07 — Verification checklist](07-verification-checklist.md).

## Fixtures — short answer

No proprietary tooling is required, but you should not glaze a panel on
sawhorses. You need three things, all shop-buildable in an afternoon:

1. **A flat glazing bench** — the reference surface that keeps rail and glass
   coplanar while the cement goes off.
2. **A squaring / centering jig** — holds the rail at 90° to the glass face and
   keeps the glass centered in the channel so cement thickness is equal on both
   sides.
3. **End dams and a pour ramp** — so the cement stays in the rail and goes in at
   a controlled rate without trapping voids.

Drawings and cut lists in [03 — Fixtures and tooling](03-fixtures-and-tooling.md).

## Status of this document

This package was written from published industry practice for wet-set all-glass
door rails and from the Por-Rok manufacturer data. **It is not a TORMAX
document.** TORMAX's own TX9200/TX9500 installation manual and the job-specific
shop drawing were not accessible from the machine this was written on (the
network policy blocked `tormaxusa.com`, `crlaurence.com`, `specchem.com` and the
manual mirrors), so every panel-specific dimension in here is written as a
**variable to be filled in from the shop drawing**, not as a TORMAX number.

Anything marked **[VERIFY]** must be confirmed before this procedure is used on
a live panel. Do not treat the typical values as approved dimensions.

Sources are listed at the end of each document.
